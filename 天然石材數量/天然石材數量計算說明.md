## 3. 計算方法


- **比例尺：** 依軸線校正，300 dpi。
  - X 向：X2～X9 = 7,700 cm，2,926 像素，2.6316 cm/像素。

### 3.2 F15 樓梯（1F～3F）

C樓梯是沿北側外牆的戶外直通梯。各層平面圖都會畫出下方樓層的梯段，若逐層描全長投影，同一段梯會重複計算。所以改依詳圖尺寸逐段計算，每段梯只計一次，計入起步樓層，計算方式同 F1 樓梯。

```
踏面＋平台 = 梯段水平長度 × 梯寬
踢面       = 級數 × 級高 × 梯寬
```

| 樓層 | 房號 | 部位 | 計算式 | 面積 (m²) |
|---|---|---|---|---:|
| 1F | 134 | 1F→2F 梯段：踏面＋中間平台 | (21×0.25 + 1.65 + 12×0.25) = 9.90 × 1.40 | 13.86 |
| | | 1F→2F 梯段：踢面 | 35 × 0.1743 × 1.40 | 8.54 |
| 2F | 203 | 2F 平台 | 2.90 × 1.40 | 4.06 |
| | | 2F→3F 梯段：踏面＋中間平台 | (13×0.25 + 1.40 + 12×0.25) = 7.65 × 1.40 | 10.71 |
| | | 2F→3F 梯段：踢面 | 27 × 0.1852 × 1.40 | 7.00 |
| 2F | 226 | D樓梯平面投影 | π × 1.275² | 5.11 |
| | | D樓梯踢面 | 27 × 0.1852 × 1.15 | 5.75 |
| 3F | 303 | 3F 平台＋往南延伸段 | 沿牆內緣描繪多邊形，從第 27 級止，到門 D12、D2 | 14.04 |
| | | 合計 | | 69.07 |

- **3F 比例尺：** 與高架地板相同。
  - X 向：X2～X9 = 7,700 cm，2.6262 cm/像素。
  - Y 向：Y6～Y1 = 3,470 cm，2.6090 cm/像素。
- **2F 比例尺：** 與 3F 同一套掃描，比對軸線位置相同，所以沿用 3F 的比例尺。
- **A3 圖上的樓梯色塊：** 只標示位置，數量以上表的計算式為準。

## 4. 數量填報

- **照實際填寫：**
  - F15：1F 22.40、2F 32.63、3F 14.04 m²。
  - F16：1F 117.89 m²。
- **施工細項表：** 比照 F 類地磚：進料 50%、打底 35%、石材鋪貼 15%。
  - 細項數量 = 本層數量 × 權重。
  - 細項百分比 = 細項數量 ÷ 該工項合計。

2026-11-18 使用者確認樓梯算法（每段梯只計一次、計入起步樓層、含踢面），並同步地坪表。以下仍為自定：
