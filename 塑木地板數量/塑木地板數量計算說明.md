高雄軟體園區第二園區第一棟大樓：景觀工程「特殊地坪，塑木地坪-W14cm,TH2.4cm」分層數量。依 `..\分層數量計算流程.md` 的流程計算。

2026-11-18 第二版：塑木範圍改以景觀平面 `XREF_平面 260825.dwg` 的木平台填線為準，並新增 1F 西側平台（依使用者指示併入 5~11F 項）。

合約依景觀工程分樓層編列。1F 西側平台在合約中沒有塑木項目，依使用者指示併入 5~11F 項（十一.5.1.2）。

- **照實際填寫：** 各層數量照圖面實際算出的數量填寫，不依合約數量調整、不加損耗。
- **合約欄：** 合約與「實際/合約」僅供對照。
- **合計：** 四項合計 1,163.18 m²，與合約合計 1,163 m² 幾乎相同。
- **5~11F 項含 1F：** 1F 西側平台 72.11 m² + 5F～11F 陽台 353.67 m² = 425.78 m²，比合約多 19.8 m²。
- **2F 塑木座椅（十一.2.5.5，1 座）：** 以「座」計，不屬本表面積項目，未列入。

## 2. 資料來源

| 資料 | 用途 |
|---|---|
| 景觀平面 `XREF_平面 260825.dwg` | 圖層 `-LA-plan-木平台`（DOLMIT 填線）的外框與內孔座標；1F、2F、4F 在景觀圖塊 LAN_1F、LAN-2F、LAN_4F 內，5F～11F 直接畫在模型空間 |
| 建築平面 A2-07～A2-17 | 對位底圖；3F 範圍（人工描繪） |
| 室內裝修表 A1-51～A1-53 | F22＝高架塑木地板，用來對照房號 |
| 施工內容 CSV | 十一.2～十一.5 景觀工程的塑木地坪合約數量 |

**DWG 讀取方式：**

- 以 LibreDWG 0.14（GitHub 正式版，GPG 簽章已驗證）的 `dwg2dxf` 轉成 DXF，再以 ezdxf 讀取座標。單位為 cm。
- DWG 參考的 4 個外部參考（軸線、現況測量、圖框）不在本機。軸線改用 DWG 內的 GRID 圖塊。

**對位方式：**

- 以各層 GRID 圖塊的 X2（或 X3）、X9、Y6（1F 為 Y4）、Y1／Y2 軸線，對到平面圖掃描影像上的軸線圓圈，X、Y 分別求比例。各層約 2.61～2.63 cm/像素。
- 疊圖檢查：2F、4F、7F 的木平台外框與建築平面的欄杆、牆線吻合，誤差約 3 像素內。

## 3. 計算方法

```
塑木面積 = 木平台填線外框面積 − 填線內孔（花台、螺旋梯、柱位）
```

- **5F～11F 陽台A：**
  - DWG 填線寬約 1.2 m，範圍是玻璃欄杆內緣到外牆。舊版依建築平面描繪時含欄杆，寬約 1.2～1.5 m，所以本版較少。
  - 每層扣 Y6、Y2 端部 2 處柱位（各 0.45 m²）。
  - 10F 頂端柱位在 DWG 重複繪製 3 個孔（0.45、0.45、0.56 m²），只扣最大的 1 個。
- **重疊的孔：** 位置重疊者只計一次。
- **3F：** 轉檔後景觀圖塊 LAN_3F 是空的（LibreDWG 未能讀出）。改用建築平面 A2-09 人工描繪的 334 範圍，已扣 4 座圓形花台、D 梯螺旋梯。

## 4. 數量填報

- **施工細項表：** 進料、龍骨組立、面板鋪設三個細項，各以本層數量 100% 計，不分權重。
- **百分比：** 每項各自加總為 100%。2F、3F、4F 各項只有一個樓層，各為 100%；5~11F 項依 1F、5F～11F 各層面積占比分配（1F 占 16.9%）。

## 5. 待確認事項

- **1F 與磁磚數量重疊：**
  - 這塊在磁磚數量裡被推定為「仿岩磚平台 61.7 m²」與「仿岩磚坡道 9.2 m²」。當時圖面沒有仿岩磚字樣，是依位置推定。
  - 景觀 DWG 標示為木平台。若確認是塑木，磁磚的仿岩磚平台、坡道位置需重新檢討。
- **3F：** LibreDWG 轉檔遺失景觀 3F 圖塊，3F 仍依建築平面描繪。若要以 DWG 為準，需改用其他轉檔器，或請提供 3F 的 DXF／PDF。
- **欄杆寬度：** 第二版以 DWG 填線（欄杆內緣）為準。若塑木要鋪到欄杆下方，5F～11F、4F 會回到第一版的數量。
