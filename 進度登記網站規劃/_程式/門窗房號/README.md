## 座標系統與校正

- **標籤明細的座標**：各層平面圖 PDF 內嵌掃描原圖的像素（不是 `*_實際數量.png`）。
  - B3F、B1F、1F、2F～11F：3307×2338（200 dpi，約 3.93 cm/像素）。
  - B2F、屋突壹層、屋突貳層：建築圖(已簽章).pdf 第 65、78、79 頁，4961×3508（300 dpi，約 2.60 cm/像素）。
- **共同座標系統**：`XREF_平面 260825.dwg`（cm）。DWG 有房號圖塊 `MARK-Room NO`（381 個，房號與網站一致）和門窗標籤圖塊（`MARK-D note`、`MARK-W note`、`MARK-SD note`、Dw）。
- **校正方式**：每層以「同代號」的門窗標籤當共同特徵點（掃描圖標籤 ↔ DWG 標籤），RANSAC 求相似轉換後，一對一配對，以最小平方求仿射轉換，剔除殘差過大的點再重算。
- **房間明細的 rect**：座標是 300 dpi 像素；200 dpi 的圖乘 2/3 即與標籤座標同系統（已用 DWG 房號驗證，B3F～11F 落在 rect 內 220/226，不符的 6 間是 rect 只量局部）。

## 房間範圍

- DWG 牆線不完整（核心區、帷幕牆缺線），所以房間範圍改用掃描圖：深色像素當牆，以 DWG 房號（轉到掃描座標）與房間明細 rect 當種子，依「離牆距離由大到小」淹水（標記式分水嶺），門洞等窄處最後才互通。
- 每間房面積上限＝房間明細面積 ×1.5（或 +8 m²），避免外漏。樓梯以 DWG 踏步線範圍當種子。
- 屋突層、8F 等沒有 rect 的房間，位置都來自 DWG 房號。

## 歸房規則

1. 取 DWG 對應門窗圖塊外擴 60 cm 範圍內的房間；只有一間 → 該間（外牆窗）。
2. 兩間：公共空間（走廊、梯廳、前室、車道、停車、大廳、門廊、風除室）與房間之間 → 歸房間；戶外（陽台、露臺、屋頂平台）與室內之間 → 歸室內側；兩側同類 → 取面積小者。
3. 複壁檢修門 DA：依判讀備註的牆向，往室內 1.5 m 取房間；落在房間明細 rect 內則以 rect 為準。
4. 自動結果逐層放大掃描圖目視核對，修正或確認寫在 `manual_src.py`（判定方式「人工」）。

## 重跑

在工作資料夾（環境變數 `DOOR_WORK`，預設 `門窗房號/_work/`，不進 git）放入 `plan.dxf`（`工具/LibreDWG-0.14-win64/dwg2dxf.exe` 轉出），先設 `PYTHONIOENCODING=utf-8`，在工作資料夾內依序執行：

1. `dump.py`、`geom.py`、`doorobj.py`：從 DXF 取房號、標籤、牆線、門窗圖塊
2. `scans.py`：取出各層掃描原圖
3. `calib.py`：校正，產生 `calib.json`
4. `scanmap.py`：各層房間標記圖
5. `manual_src.py`：人工核定 → `manual.json`
6. `assign.py`：歸房
7. `export.py <輸出 csv>`、`plot2.py <核對圖資料夾>`
8. `review.py <樓層> x0 y0 x1 y1 [倍率]`：放大檢視用
