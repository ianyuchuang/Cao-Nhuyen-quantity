## 說明

- **規劃頁**：`進度登記網站規劃.html`，網址見上表。
- **資料來源**：各工項的 `*_數量計算表.xlsx`，加上每日施工內容 CSV「施工-實際進度 (修訂2版)」。
  - 從 CSV 只取層級、項目、單位、合約數量和使用數量，**不取單價、複價**。
  - CSV 不進 git（見 `.gitignore`）。
- **正式版「高軟每日施工內容(正式版)」只能讀取、複製**，任何程式都不寫入。

```
進度登記網站規劃/
├─ template.html           規劃頁原稿（第七版）：資料規模、流程、計算規則、5 個互動版面、決策紀錄、實作階段
├─ review.html             Fable 5.2 的審查意見與處理方式（建置時注入規劃頁）
├─ 進度登記網站規劃.html   建置結果（template＋資料＋審查），可直接用瀏覽器開
└─ _程式/
    ├─ extract.py           萃取資料 → data.json，再建置規劃頁
    ├─ data.json            工項 → 代號 → 樓層 → 房間 → 圖面數量（12 工項、188 代號、2,056 位置）
    ├─ build_sheet.py       由 data.json 產生要匯入試算表的「位置」「分層進度」分頁
    └─ 工項進度登記_匯入.xlsx
```

## 重新產生

在 `D:\分層數量` 依序執行。Windows 主控台要設 UTF-8，否則印中文會出錯。

```bash
PYTHONIOENCODING=utf-8 python 進度登記網站規劃/_程式/extract.py
```

```bash
PYTHONIOENCODING=utf-8 python 進度登記網站規劃/_程式/build_sheet.py
```

- 需要 `openpyxl`。
- 上層資料夾要有各工項的數量計算表、`分層數量表_地坪及貼面磚.xlsx` 和每日施工內容 CSV。
- 計算表的公式格沒有快取值，所以 `extract.py` 自己算公式。支援四則運算、`SQRT`、`^`、儲存格參照和 `SUM` 範圍。
- 門窗依「標籤明細」展開到每一樘。程式會逐層核對樘數是否和計算式一致，不一致就停止。
- 樓層一律用以下 17 個，順序固定：代號層、筏基層、B3F～B1F、1F～11F、屋突層。
- `build_sheet.py` 在 CSV 找不到層級、位置ID 重複，或樓梯踢面／坡道斜面找不到要併入的房間時，都會停止。
  - 樓梯踢面併入同層的樓梯房間。
  - 坡道斜面併入同層同房號。
  - 這兩項是 2026-11-19 使用者要求的。

圖面數量改了以後的更新步驟：

1. 重跑上面兩支程式。
2. 修改程式裡的 `VERSION`（數量版本）。
3. 把新的「位置」分頁內容貼進試算表「工項進度登記」。
4. 在試算表選單重算。

## 已定的設計決策

- **流程**：工項 → 樓層 → 房間 → 代號細項 → 面積，填完成 %。
- **填寫層級**：
  - 樓層、房間、代號三層都可以填。
  - 上層的值會覆蓋底下全部；底下有不同值時，先提示再覆蓋。
  - 比例分配的數量只能在代號層填。
- **進料**：在代號層整批填數量。
- **門窗**：展開到每一樘，分兩個細項，各佔 60／40：
  - 門：門框／門扇及五金
  - 窗：窗框／玻璃及五金
  - 捲門：導軌及捲軸箱／門片及電動機
- **計算**：
  - 完成量 = 圖面數量 × 完成 %。
  - 房間、樓層的 % 依數量加權，只在同一個單位內合計。
  - 每日數量 = 當日累計 − 前一日累計。
  - 輸出直接用圖面完成量，不換算成合約數量。
- **期初**：期初 % = 正式版使用數量 ÷ 圖面合計，依比例平均設到各位置。使用數量超過圖面的 7 個代號，期初以 100% 計。
- **生效方式**：直接生效，不審核、不日結。已到 100% 的代號不特別處理。
- **以正式版為準**：
  - 試算表的主表「施工-實際進度」是正式版的鏡像，只讀同步。
  - 網站的結果寫到「網站每日數量」，和正式版的差異列在 I 欄。
  - 要不要填進正式版，由內業決定。
- **架構**：
  - 網頁放 GitHub Pages，用 Google 帳號登入。
  - Apps Script 當 API，以擁有者身分執行。
  - 資料庫是 Google 試算表「工項進度登記」。
- **其他工項**：等算完分層數量再加入。

- **權限**：用「人員」表核准，試算表「設定」的權限來源填「人員表」。
  - 工程師不共用試算表。第一次登入網站時會自動加進人員表，狀態是待核准；改成「核准」後才能登記。
  - 試算表編輯者就是網站的編輯者：可以看全部人的紀錄、全部重算，也能直接改表。
  - 只看不登記的人才共用成檢視者。他們會看到主表的單價、複價，而且不能登入網站登記。
